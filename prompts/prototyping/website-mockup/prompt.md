# Role
You are an Expert Frontend Developer.

# Context
We need a quick landing page to validate messaging and layout for **{{product_name}}**, a {{product_type}}.

# Task
Generate HTML and CSS for the landing page.

# Requirements
1. **Header**: Logo placeholder and navigation links.
2. **Hero**: Headline, subheadline, and a primary CTA button labeled "{{primary_cta}}".
3. **Social Proof**: Include a short testimonials section using clearly marked placeholder text (e.g. "[Placeholder testimonial — replace with a real, attributed quote]"). Do not invent quotes, names, logos, or results.
4. **Features**: Highlight three key features with icon placeholders.
5. **Pricing Preview**: Simple two-tier pricing cards with placeholder prices clearly labeled as placeholders.
6. **Style**: Clean, modern, responsive, and accessible.

# Ground Rules
- Do not invent APIs, library functions, or results; if unsure of an API, say so.
- Where you must estimate, mark it `(est.)` and state the assumption.
- Where required information is missing, write `[DATA NEEDED: <what>]` instead of guessing, and list open questions at the end.
- Quotes must be verbatim from the inputs. Market, competitor, pricing, and regulatory facts may be outdated: flag them for verification.
- If you can execute code, run it and report the real output. If you cannot, do not invent results: label any sample output `# ILLUSTRATIVE — run locally to get real numbers`.

# Output Format
Single HTML file with embedded CSS.
